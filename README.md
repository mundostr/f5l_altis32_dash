# F5L ALTIMETER DASHBOARD

The dashboard is installable as a Progressive Web App when served over HTTPS. It caches the app shell for offline startup after the first visit. Use **Check updates** in the top-right corner to compare the running version with the one deployed on Railway and activate a newer version.

When publishing a release, update `WEB_VERSION` in `index.html` and the matching cache version in `sw.js`.
